# Olist E-Commerce Analysis

End-to-end analysis of the Brazilian E-Commerce Public Dataset by Olist, covering data cleaning, exploratory analysis, and an interactive Power BI dashboard.

## Project Objective
Analyze orders, revenue, customers, payments, and delivery performance to find sales trends and the factors behind them.



## Key Questions
- How do sales and revenue change over time?
- Which states and product categories bring the most revenue?
- Which payment methods do customers prefer?
- How do delivery delays affect review scores?


## Tools Used
Python (Pandas, Matplotlib), SQL, Power BI (DAX), Streamlit

## Project Structure
- `datasets/`: sample data
- `notebook/`: analysis notebook
- `scripts/`: Python and SQL scripts
- `images/`: dashboard screenshots
- `requirements.txt`: Python libraries

## How to Run
pip install -r requirements.txt
jupyter notebook notebook/
